## 🚀 Projetos

### 🟣 DeviceX

**Sistema web para gerenciamento de assistência técnica de dispositivos eletrônicos.**

Aplicação full-stack desenvolvida para auxiliar no gerenciamento de clientes, dispositivos e ordens de serviço de uma assistência técnica.

#### Funcionalidades

- 🔐 Autenticação com JWT
- 👥 Gerenciamento de clientes
- 💻 Gerenciamento de dispositivos
- 🧾 Gerenciamento de ordens de serviço
- 📋 Histórico de status das ordens
- 👤 Controle de usuários e permissões
- 📊 Dashboard
- 🔒 Proteção de rotas e recursos
- 🗄️ Persistência de dados com PostgreSQL

#### Tecnologias

**Front-end:** React, Vite, JavaScript, React Router e CSS

**Back-end:** Java, Spring Boot, Spring Security, JPA e JWT

**Banco de dados:** PostgreSQL

🔗 **Repositório:**  
https://github.com/PedroLagoX/DeviceX

> 🌐 Demonstração online será adicionada após o deploy do projeto.

### 🐾 APANIM

**Sistema web para adoção, doação, compra e venda de animais, além de divulgação de animais perdidos.**

Projeto desenvolvido como **Trabalho de Conclusão de Curso**, com foco na criação de uma aplicação web utilizando tecnologias modernas de desenvolvimento front-end.

#### Funcionalidades

- 🐶 Cadastro e divulgação de animais
- 🏠 Adoção
- ❤️ Doação
- 🔎 Divulgação de animais perdidos
- 🛒 Compra e venda
- 📱 Interface responsiva
